18class ColorGradient {

32 TRUNCATED,

39 // Creates a gradient specification, given the list of nodes and an option al
40 // boundary specification. The node list must contain at least one node for
41 // EXTENTED and TRUNCATED gradients, and at least two nodes with different
42 // values for PERIODIC gradients. The nodes must be sorted by value. The
43 // values in successive nodes can be equal; such condition indicates a sharp

122 // Creates a linear gradient. The color value is calculated as:
