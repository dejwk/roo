12// Transformation classes describe various types of transformations.
13// Translation, Scaling, and Rotation are primitive transformations.
14// AffineTransformation is a combination of translations, scalings, and
15// rotations. Use 'then()' (described below) to compose transformations.
16
17// All transformation classes have some common methods:
18// * apply(FpPoint): calculate the transformation for a given point.
19// * then(TransformationType t): composes t with this transformation, returning
20// a new composed transformation.
21// * inversion(): returns a transformation that is the inverse of this
22// transformation.
23// * transformExtents(Box): calculates a bouding box that encapsulates all
24// transformed pixels from the specified box.
25
26// Avoid declaring transformations explicitly; prefer auto and the construction
27// methods defined below.
28
29class IdentityTransformation;
30class Translation;
31class Scaling;
32class Rotation;
33class AffineTransformation;

289 FpPoint orig = inverse_transformation_.apply(FpPoint{x[i], y[i]});
290 int16_t xMin = (int16_t)floorf(orig.x);
