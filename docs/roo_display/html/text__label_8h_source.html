15// A single-line, single-colored. text label, with extents that have height
16// based only on the font size, but not on the specific text. The origin is at
17// the text's reference point; i.e. at the text baseline, and horizontally
18// affected by the text's bearing.
19//
20// When using smooth fonts, you should generally specify bgcolor when drawing
21// text labels, even over pre-filled solid backgrounds. This is because device
22// drivers often do not support alpha-blending, which is required for properly
23// rendering smooth font edges. The exception is when you draw to Offscreen, or
24// double-buffered devices, or devices whose drivers that do actually support
25// alpha-blending, AND when you want to preserve the existing non-solid
26// background.
27//
28// When using for text fields whose values may be changing on the screen,
29// you want to enclose TextLabel in a Tile, which supports flicker-less
30// redrawing.
31//
32// See also StringViewLabel.
33class TextLabel : public Drawable {
34 public:
35 template <typename String>
