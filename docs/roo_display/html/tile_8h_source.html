72// Tile is a rectangular drawable with a single-colored background and an
73// arbitrary interior (represented by a separate drawable). Tile is useful
74// for drawing UI widgets, such as icons, text boxes, etc., which occupy
75// rectangluar spaces. Tile handles auto-alignment and flickerless
76// redraws.
77//
78// Alignment: the Tile re-posiions the interior within its bounding rectangle,
79// according to the alignment specification, separately for horizontal and
80// vertical axes ({ TOP, MIDDLE, BOTTOM }, { LEFT, CENTER, RIGHT }), with
81// optional absolute offsets. The original absolute extents of the interior
82// are ignored in that case; only the width and height of the interior are
83// affecting its position within the tile. Alternatively, you can also disable
84// re-positioning, and use the interior's absolute extents.
85//
86// Flickerless redraws: A naive way to draw the tile would be to fill-rect the
87// background, and then draw the interior. That, however, would draw certain
88// pixels twice, causing flicker and slowness. To minimize or avoid this effect,
89// the tile is drawn as (up to) 5 non-overlapping sections: top border, left
90// border, interior, right border, bottom border. If the interior itself
91// supports no-flicker redraws, the tile is redrawn completely without flicker.
92//
93// The Tile can be created with a (semi)transparent background. In this case,
94// bgcolor provided when the tile is drawn will dictate the effective
95// background color of the tile: the effective background color will be
96// the tile's bgcolor alpha-blended over the bgcolor specified at draw time.
97// This feature is useful e.g. to visually differentiate state of UI widgets,
98// e.g. active, inactive, selected, clicked, etc.
99class Tile : public internal::TileBase {
100 public:
101 // Creates a tile with the specified interior, extents, alignment, and
102 // optionally background color.
103 Tile(const Drawable *interior, Box extents, Alignment alignment,
104 Color bgcolor = color::Background)
105 : internal::TileBase(*interior, extents, alignment, bgcolor),
106 interior_(interior) {}
107
108 void drawTo(const Surface &s) const override {
109 TileBase::draw(s, *interior_);
110 }
111
112 private:
113 const Drawable *interior_;
114};
