12// Convenience wrapper to efficiently read data from the underlying input
13// stream. Uses a small buffer (64 bytes) to avoid tiny reads from the
14// underlying stream. It owns the stream if constructed with a unique_ptr,
15// otherwise it just references it. In any case, once you create a reader, do
16// not use the underlying stream explicitly anymore (doing so would interfere
17// with the buffer used in this class). The stream is closed when the reader is
18// destructed or closed explicitly.
