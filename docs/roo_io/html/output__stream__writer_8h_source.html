12// Convenience wrapper to efficiently write typed data to the underlying output
13// stream. Uses a small buffer (64 bytes) to avoid tiny writes to the underlying
14// stream. It owns the stream if constructed with a unique_ptr, otherwise it
15// just references it. In any case, once you create a writer, do not use the
16// underlying stream explicitly anymore (doing so would interfere with the
17// buffer used in this class). The stream is closed when the writer is
18// destructed or closed explicitly.
